Краткая теория

Кратко о вайбкодинге

Что такое вайбкодинг, какие ИИ использовать и какие педагогические задачи помогает решать интерактивный тренажер.

Что такое вайбкодинг?

Это создание цифрового продукта через запросы к искусственному интеллекту на естественном языке: учитель описывает задачу, получает рабочий образец, проверяет его и вносит правки.

Педагогический принцип: нейросеть помогает писать код, а учитель определяет содержание, сложность, дидактическую цель и качество результата.

Какие ИИ можно использовать?

Для апробации удобно использовать ИИ, рекомендованные АО: DeepSeek, Kimi, Qwen. Подойдут и другие сервисы, если они умеют работать с файлами, изображениями и длинными запросами.

Важно: независимо от выбранного сервиса учитель проверяет извлеченные сведения, правильность ответов и удобство интерфейса.

Где можно применить тренажер?

На этапе актуализации

Случайные карточки, домино, блиц-вопросы и разминка помогают быстро включить в работу весь класс.

На этапе закрепления

Соответствия, хронология, понятия и даты делают повторение более наглядным и деятельностным.

Для дифференциации

Ученик может работать в своем темпе, повторять ошибки и получать задания разного уровня сложности.

Для самостоятельной работы

Автономный HTML-файл открывается без интернета и подходит для домашнего повторения и самопроверки.

Для подготовки к ЦТ / ЦЭ

Тренажер удобен для систематического повторения дат, понятий, персоналий и типовых заданий.

Для учителя

Это способ быстрее тиражировать материалы, обновлять задания и сохранять удачные разработки для разных классов и тем.

От собственного материала к HTML-тренажеру

Применяем единый алгоритм из памятки. Участники выбирают одну педагогическую задачу, загружают учебную карточку, фото или файл и проверяют извлеченные сведения.

Алгоритм участника

3. «ОК»Подтверди данные перед генерацией
4. СОЗДАЙВыбери формат А, Б или В и получи HTML

Универсальный стартовый промпт

Шаг 1: сначала проверь материалы, не пиши код. После подтверждения «ОК» — переход к выбранному маршруту.

Ты — методист и разработчик учебных HTML-тренажеров для учителей истории и обществоведения Республики Беларусь. Предмет: [ПРЕДМЕТ], класс: [КЛАСС], тема: [ТЕМА]. Цель: [ПОВТОРЕНИЕ / ИГРА / ПРАКТИКА]. Я прикрепляю [ТИП ФАЙЛА ИЛИ НЕСКОЛЬКО ФАЙЛОВ] с учебным содержанием. ШАГ 1 — СНАЧАЛА ПРОВЕРЬ МАТЕРИАЛЫ, НЕ ПИШИ КОД. Укажи, какие файлы удалось прочитать полностью, какие частично. Извлеки сведения, необходимые для выбранного задания. Покажи таблицу «№ — вопрос/ситуация — правильный ответ — место в источнике». Отметь сомнения, повторы, неоднозначности. Не выдумывай факты, даты, статьи, ссылки, цитаты. Если есть конфликт источников, спроси меня. Дождись моего сообщения «ОК». ШАГ 2 — ТОЛЬКО ПОСЛЕ «ОК»: СОЗДАЙ ОДИН АВТОНОМНЫЙ HTML-ФАЙЛ. Весь HTML, CSS и JavaScript должны находиться внутри файла. Никаких внешних библиотек, шрифтов, картинок, CDN, сетевых запросов, входа по аккаунту и сбора персональных данных. Понятный текст заданий, крупные кнопки, адаптация к телефону и компьютеру и разным средам, понятный счет или самооценка, перезапуск. Не показывай правильный ответ до попытки ученика (кроме специального режима теоретических карточек). Используй ТОЛЬКО согласованные данные. ШАГ 3 — ВЫДАЙ РЕЗУЛЬТАТ. Дай готовый .html для скачивания; если сервис не умеет прикрепить файл — полный код без сокращений и инструкцию по сохранению в UTF-8. Скажи, что проверено логически, а что реально проверено в браузере; не утверждай о тестировании, которого не было.

Промпт аудита

Проверяем факты, неоднозначные ответы, работу кнопок, начисление баллов, мобильный режим и автономность.

Проведи методический и технический аудит моего тренажера. 1) Сверь каждую запись с утвержденной таблицей, сохрани исходный объем. 2) Найди неправильные ключи и неоднозначные задания, особенно вопросы с несколькими подходящими ответами. 3) Проверь логику начисления баллов, запрет преждевременного показа ответа, перезапуск, пустые состояния и мобильную верстку. 4) Если тестирование в браузере недоступно, укажи это. 5) Исправь ошибки и верни ПОЛНЫЙ новый HTML, без пропусков, не уничтожая рабочие режимы.

После «ОК» выберите один маршрут

В раздатке предложены три направления. Достаточно одного небольшого результата для первой пробы. Кнопки ниже копируют соответствующий учебный промпт.

А. Повторение: карточки, пары, тест

Промпт А

Даты, понятия и исторические личности; самооценка и возвращение к трудным карточкам.

Возьми загруженные файлы. Проанализируй записи. Выбери даты, термины с определениями и характеристики исторических личностей. Создай: (1) карточки «вопрос → раскрыть ответ → самооценка “Знаю / Частично / Не знаю”»; (2) игру «Найди пару»; (3) мини-тест на 5 вопросов с итогом и повторением ошибок. Если данные содержат даты, добавляй хронологию только при однозначном порядке; периоды с перекрытием не смешивай. Не требуй вводить развернутый ответ.
Б. Игра: домино или командная викторина

Промпт Б

Подходит для разминки, групповой работы и быстрого повторения. Образец такого результата — викторина «1812 год» ниже.

Возьми согласованные записи и сделай игру по типу исторического домино / викторины «Своя игра». Выбор: [ПАРЫ / ВИКТОРИНА]. Для пар: два перемешанных столбца, щелчок по двум карточкам, проверка, подсчет, кнопка «Сыграть снова». Для викторины: стартовый экран, поле категорий, по одной карточке вопроса, отдельная кнопка раскрытия ответа, учет баллов 2–3 команд вручную ведущим или автоматически после выбора команды, возврат к полю, запрет повторного выбора сыгранного вопроса. Не выводи ключ до действия участника. Не требуй проектора: интерфейс должен работать на обычном экране.
В. Практика: ситуации, подсказки, объяснение

Промпт В

Для применения исторического и обществоведческого знания в учебных ситуациях.

Возьми загруженные файлы. Проанализируй записи. На основе согласованных положений составь короткие учебные ситуации, в которых надо выбрать понятие / принцип / статью и объяснить выбор. У каждой ситуации: вопрос с вариантами выбора, затем по нажатию первая подсказка, вторая подсказка, образец аргументации, самооценка «Знаю / Частично / Не знаю». Не заставляй печатать развернутый ответ. Важно: оценивать не только угадывание номера, но и соответствие сути ситуации. Исключи неоднозначные сюжеты, где на равных подходят несколько ответов.

Скопируйте нужный промпт и вставьте его в чат с ИИ.

Два способа получить HTML

Способ 1. Скачать готовый файл. Если нейросеть предлагает кнопку Download, скачайте .html, откройте его в браузере и проверьте задания.

Способ 2. Сохранить код через «Блокнот». Если ИИ выдал код текстом, скопируйте его полностью и выполните пять шагов ниже.

Важно: исходный файл с кодом должен иметь расширение .html, а не .txt или .html.txt. В окне сохранения выберите «Все файлы (*.*)».

Найдите его в меню «Пуск» → «Стандартные — Windows».

2. Или создайте TXT

На рабочем столе: правая кнопка мыши → «Создать» → «Текстовый документ».

3. Откройте текстовый файл

«Открыть с помощью» → «Блокнот». Вставьте полный HTML-код из ответа ИИ.

4. Выберите «Сохранить как…»

Меню «Файл» → «Сохранить как…»; укажите папку для тренажера.

5. Укажите правильный формат

Имя: trenazher.html. Тип: «Все файлы (*.*)». Кодировка: UTF-8. Нажмите «Сохранить».

Обратите внимание на пятый скриншот: на нем еще выбран тип «Текстовые документы (*.txt)». Перед нажатием «Сохранить» обязательно измените тип на «Все файлы (*.*)» — иначе Windows может добавить расширение .txt.
6.Найдите trenazher.html в сохраненной папке. Откройте двойным щелчком или через «Открыть с помощью» → браузер.
7.Пройдите несколько заданий, проверьте подсказки, ответы и работу кнопок. По возможности отключите интернет для проверки автономности.
